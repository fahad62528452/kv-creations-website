# KV Creations Website

Luxury marketing site for **KV Creations**, a wedding planning and event management atelier.

## Brand

- Gold `#D8B386`
- Maroon `#2B0C0C` / Maroon Core `#190504`
- Display: Cinzel
- Body: Montserrat

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
